## 1. 快速上手（3 分钟）

1. **解压即用**：把 `TagVault-portable` 文件夹拷到任意电脑（Windows 10/11 x64），双击 **「启动标签管家-静默.vbs」**，浏览器自动打开 `http://localhost:48765`。无需安装 Node.js 或任何环境。
2. **添加要管理的文件夹**：页面右上角「设置」→「索引目录」→「添加目录」→ 选择文件夹（首次弹系统选择框可能稍慢，之后变快）。程序自动扫描全部文件。
3. **打标签**：
   - 单击任意文件 → 右侧出现详情面板 → 在「快速添加标签」输入框直接输入（如 `客户A项目`）→ 回车即打上；
   - 想一次给很多文件打标：按住 **Ctrl 点选**（或 **Shift 范围选**）多个文件 → 顶部蓝色工具条输入值 → **回车**，全部所选文件一次性打上。
4. **搜索**：顶部搜索框输入即搜。可以搜纯关键词（`海报`），也可以按字段精确过滤（`保密级别:机密`）。

就这么多。下面是完整功能说明。

## 2. 启动与部署

### 便携版文件结构

```
TagVault-portable/
├─ 启动标签管家-静默.vbs    ← 推荐：无黑窗口后台运行，浏览器自动打开
├─ 启动标签管家.bat         ← 需要看实时日志时用：有黑色控制台窗口，关窗即停
├─ 停止标签管家.bat         ← 停止后台运行的服务
├─ 使用说明.txt             ← 精简版说明（本手册的浓缩版）
└─ app/
   ├─ node.exe              ← 内置运行时，目标电脑无需装任何环境
   ├─ data/                 ← 数据库与缩略图缓存（备份=备份这个目录）
   ├─ logs/tagvault.log     ← 运行日志（静默模式排查问题看这里）
   └─ config.json           ← 端口等配置（首次启动自动生成）
```

### 启动方式（任选其一）

| 方式 | 特点 | 适合 |
|---|---|---|
| `启动标签管家-静默.vbs` | 无窗口后台运行，日志写入 `app\logs\tagvault.log` | 日常使用 |
| `启动标签管家.bat` | 显示黑色控制台实时日志，**关闭窗口即停止服务** | 调试排查 |

### 停止服务

- bat 方式：直接关闭黑色窗口；
- 静默方式：双击「停止标签管家.bat」，或在任务管理器结束对应的 `node.exe` 进程。

### 端口规则（自动处理，一般不用管）

- 默认端口 **48765**；被占用时启动器**自动改用下一个空闲端口**（48766、48767…），日志里会写「本次使用端口：xxxxx」，浏览器自动打开正确地址。
- **重复双击不会开出多个实例**：检测到已在运行会直接帮你打开浏览器。
- 想固定端口：在 `app\config.json` 写 `{"port": 48765}`（也可在页面「设置」里改，改完需重启）。
- 高级：启动前设置环境变量 `TV_PORT=xxxx` 可临时指定端口。

## 3. 核心功能详解

### 3.1 索引管理（自动更新与移动追踪）

**添加 / 移除索引目录**：设置 →「索引目录」。移除目录会二次确认（询问是否连文件记录一起清）。

**新文件自动入库**：程序对已索引的文件夹开启**实时监听**——新增、修改、删除的文件约 **1 秒内**自动同步到列表，无需手动扫描。监听到变化时右上角会弹轻提示。

**启动回扫**：每次启动软件时自动重扫全部目录，把程序关闭期间错过的变更补录进来。

**文件挪动/改名，标签不丢**（接力机制）：

| 场景 | 结果 |
|---|---|
| 同目录内改名/移动 | 标签原样保留，路径自动更新 |
| 在两个已索引目录之间移动 | 标签保留，所属目录自动更新 |
| 移出已索引目录 | 文件标记为「缺失」（标签仍保留） |
| 移回已索引目录 | 自动恢复，标签原样回来 |
| 移动期间程序正好关闭 | 下次启动的回扫同样识别接力，标签不丢 |

> 原理：扫描时按「文件大小 + 修改时间」匹配缺失记录，识别出是同一个文件后只更新路径。

**缺失文件管理**：设置里有缺失列表，可一键全量检查；确认文件永久丢失后可「清理缺失记录」。

### 3.2 未打标签提醒

顶栏有 🔔 **「未打标签 N」** 徽标，实时显示还没有任何标签的文件数量：

- 点击徽标 → 自动筛选出全部未打标签文件；
- 再次点击（或点筛选条上的「未打标签」标签片）→ 取消筛选；
- 监听到新文件入库时也会弹提示，配合 🔔 及时补打标签。

### 3.3 标签体系（类型 + 值）

标签是二维的：**类型（是什么维度）+ 值（该维度的取值）**。

- 预置 9 个类型：保密级别、版本状态、项目、用途标签、物料类型、内容说明（自由）、优先级、审批状态、归档年份（均为自由输入，可在设置中增删改）。
- 每个类型两种模式：
  - **自由输入**：任意值都能打（打过的值自动登记进字典，方便复用）；
  - **枚举**：只能从字典白名单里选，防止打错字。
- **「未分类」类型受保护**：未指定类型的标签自动归入它；它不能被改名/删除，但其中的标签值可以在设置里整理（改名、移动到其他类型）。

### 3.4 三种打标方式

#### ① 单文件：右侧详情面板

单击文件 → 右侧面板自动打开：

- **快速添加**：输入即弹出联想建议（按使用频次排序、精确匹配置顶），回车打标；支持逗号分隔一次加多个；字典里没有的值自动归入「未分类」；
- **按类型添加**：展开某个类型——枚举类型显示复选框列表（带过滤、「已挂」标记、使用次数）；自由类型直接输入多值；
- **去标**：标签旁的 ✕ 一键移除。

#### ② 多选批量：顶部蓝色工具条（选中 >0 个文件时出现）

**零操作直接用**：不用选类型，直接在输入框输入值 → **回车**（或点「批量打标」）→ 全部所选文件打上该标签，自动归入「未分类」。支持逗号分隔一次加多个值。

需要按类型时：下拉选定类型（枚举类型变为下拉选值），其余操作相同。

三个去标按钮，力度从轻到重：

| 按钮 | 行为 |
|---|---|
| **批量去标** | 填了值 → 只移除指定值；**不填值 → 移除所选文件该类型下的全部标签**（有确认框） |
| **清空全部标签**（红色） | 移除所选文件的**所有类型**的全部标签（有确认框） |
| **全清选择** | 只是取消勾选，不动标签 |

#### ③ 多选时的右侧面板：批量模式

Ctrl/Shift 多选后，右侧面板自动切换为**批量模式**（标题显示「已选 N 个文件（批量模式）」+ 蓝色提示条）：

- 快速添加、按类型勾选、标签 ✕ 去除——**全部操作作用于所有所选文件**；
- 标签区显示所选文件的**标签并集**；「只有部分文件拥有」的标签带黄色「**部分**」徽标；枚举复选框区分「已挂（全部都有）/ 部分 / 未挂」三种状态；
- 勾选/取消枚举值会同步到全部所选文件（勾上 = 全部添加，勾掉 = 全部移除）；
- 锚点为最后点击的文件；一次操作上限 50 个文件的并集展示（超出时提示仅显示当前文件，操作仍作用于全部）。

### 3.5 右键菜单

文件行/缩略图上右键：

- **打开**：用系统默认程序打开该文件；
- **打开所在文件夹**：在资源管理器中定位该文件；
- **复制路径**：完整路径进剪贴板；
- **编辑标签**：聚焦右侧面板的快速添加输入框。

### 3.6 搜索

- **输入即搜**：150ms 防抖，边打字边出结果；本地索引，几千个文件毫秒级响应。
- **字段化语法**：`类型:值`，如 `保密级别:机密`、`项目:年会`；多个条件之间是「且」的关系。
- **关键词**：纯文本匹配文件名；多个关键词是「或」的关系，命中任一即返回。
- **左侧筛选栏**：按文件类别（图片/PDF/Word/…）勾选；按标签类型的值勾选， facet 上直接显示各类值的文件数。
- **只看定稿**：勾选后只显示**任意类型**的标签值中含「定稿」字样的文件（不必叫「定稿」这个类型名，自定义类型里的「XX定稿」同样命中）。
- **未打标签筛选**：见 3.2。
- 搜索条件会在筛选条上以标签片展示，单个可删，一键全清。

### 3.7 视图与排序

- **表格视图**：文件名、类型图标、标签、大小、修改时间等列。
- **缩略图视图**：图片自动生成缩略图（懒加载），预览直观。
- **排序**：文件名 / 修改时间 / 大小，升降序可切换；偏好自动记住。
- 列表滚动到底自动加载下一页。

### 3.8 标签类型管理（设置 →「标签类型管理」）

- **新建类型**：命名 + 选枚举/自由模式；类型名不能含冒号、≤30 字符、不可重名。
- **改名 / 显隐 / 排序（▲▼）**：改名会**同步更新所有已打标签和搜索索引**，旧名搜不到、新名立即生效。
- **删除类型**：二次确认（先告知影响多少文件），删除后其字典与标签级联清除。
- **字典值管理**：新增、改名（同步全部已打标签）、**移动到其他类型**（带走全部已挂标签，可移动到新类型）、删除（级联移除该值全部标签，二次确认）。
- 用途举例：把散落在「未分类」里的临时标签值批量移动到一个正式类型，完成标签治理。

### 3.9 数据导入 / 导出 / 备份

- **导出 JSON**：完整备份（类型、字典、标签全量），可用于迁移或二次处理。
- **导出 CSV**：表格形式（路径 + 各类型标签列），Excel 打开即用（UTF-8 BOM，中文不乱码）。
- **导入**：选择之前导出的 JSON 恢复；按路径匹配文件，未匹配的会列出清单。
- **最简备份**：直接拷贝 `app\data\` 目录（数据库 + 缩略图都在里面）。

### 3.10 设置项

| 设置 | 说明 |
|---|---|
| 索引目录 | 增删要管理的文件夹、单个重扫、全量缺失检查 |
| 标签类型管理 | 见 3.8 |
| 端口 | 默认 48765，改后需重启服务 |
| 数据目录 | 数据库存放位置 |
| 自动打开浏览器 | 启动后是否自动弹出页面（可关） |

## 4. 数据存储位置与迁移

| 内容 | 位置（便携版） |
|---|---|
| 数据库（全部标签/类型/目录，单文件 SQLite） | `app\data\tagvault.db` |
| 缩略图缓存 | `app\data\thumbs\` |
| 配置（端口等） | `app\config.json` |
| 运行日志 | `app\logs\tagvault.log`（超 2MB 自动轮转） |

- **备份** = 备份 `app\data\`；
- **迁移到新电脑** = 整个 `TagVault-portable` 文件夹拷走，标签数据随包带走；
- 本工具**完全离线**，无任何网络请求。

## 5. 常见问题

**Q：双击 bat 一闪而过？**
端口被占用时会自动换端口并提示；若仍失败，把 `app\config.json` 的 `port` 改成其他数字再启动。

**Q：浏览器没自动打开？**
看 `app\logs\tagvault.log` 里的「本次使用端口」，手动访问 `http://localhost:该端口`。

**Q：文件打不开 / 打开是旧版本？**
确认服务在运行（日志有「服务已启动」）；浏览器按 F5 刷新页面加载最新前端。

**Q：多选批量打标没生效？**
注意顶部工具条和右侧面板在多选时都是「作用于全部所选文件」；若在右侧面板操作但面板没显示「批量模式」，说明当前只选中了一个文件。

**Q：误删了标签怎么办？**
删除类型/字典值有二次确认；但单文件去标、批量去标是直接生效的——可用「导出 JSON」的日常备份通过导入恢复。

**Q：杀毒软件报提示？**
本工具完全离线、无网络请求，可放心放行。

**Q：📂 选择文件夹弹窗很慢？**
首次调用系统对话框较慢属正常，之后会明显变快。

## 6. 技术概要（运维/开发向）

- **运行时**：内置 Node.js 22，免安装；Windows 10/11 x64。
- **架构**：Express 4 + better-sqlite3（FTS5 trigram 全文索引 + 触发器同步）后端；React 18 + Vite + TypeScript + Tailwind + zustand 前端；chokidar 实时监听；sharp 缩略图；SSE 推送扫描/文件变更进度。
- **接口约定**：`{code:0, data, message}`；`40910`=需二次确认（响应携带影响数）；`40911`=「未分类」保护；`42201/42202/42203`=校验错误。
- **关键接口**：`POST /api/tags/batch`（批量打标/去标，`values` 为空 + `remove` = 按类型整类去标）、`POST /api/tags/clear`（清空所选文件全部标签）、`GET /api/system/untagged`（未打标签计数）。
- **质量**：Vitest + Supertest 49 个自动化测试全绿（覆盖打标/批量/整类去标/清空/搜索语法/字典同步/移动接力等）。
- **源码位置**：`TagVault/`（`server/` 后端、`client/` 前端、`tests/` 测试、`docs/` 设计文档）；`npm test` / `npm run build` / `npm start`。
