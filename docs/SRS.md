# 标签管家（TagVault）需求规格说明书 v1.3

> v1.3（2026-11-25）更新：吸收首轮搭建与三轮迭代增强的全部结论——实时监听提速、启动回扫、移动/改名标签接力、未打标签提醒、批量打标零选择直输、按类型整类去标、一键清空、多选批量模式、端口自动回退、静默启动、便携版交付等。变更处标注「v1.3」。

## 1. 产品概述
一句话定位：一个本地运行的文件/图片标签检索工具：给电脑里的文件、图片打上多维标签，像 Everything 一样"输入即搜"，快速找到需要的文件——文件本体一根毫毛都不动。
目标用户：需要管理大量图片与文档的个人用户，单机使用。
核心价值：不打乱现状（不复制、不搬移、不改名，标签存在工具自己的数据库里）；标签是资产（类型和值完全自定义，随时增删改排序，可导出备份）；快（万级文件输入即搜，实测中位 8ms，组合筛选：同类型多选=或，跨类型=且）；零依赖（完全离线、无账号、无云同步，数据单文件 SQLite 随目录搬走）。

## 硬性设计原则（不可违背）
1. 文件原地不动：工具只读元数据（路径/大小/时间），永不写用户的文件
2. 显式索引：不做全盘扫描，只索引用户添加的目录；不做文件树
3. 单文件存储：一个 SQLite 库（含 FTS5 全文索引），缩略图缓存与库同目录，整体可搬
4. 完全离线：无网络请求、无账号、无遥测
5. 输入即搜：搜索框不按回车、150ms 防抖即时出结果

交付形态（v1.3）：
- 开发运行：`npm start` 一条命令启动，浏览器访问 http://localhost:48765
- **便携版交付**（v1.3）：`TagVault-便携版.zip`，内置 Node 运行时，目标电脑免安装免环境，双击「启动标签管家-静默.vbs」即用（详见用户手册）

## 2. 功能需求

### 2.1 索引管理
- IDX-1 添加索引目录：①"📂 选择文件夹"弹出系统对话框；②直接粘贴路径回车。两者并存
- IDX-2 扫描入库：后台递归扫描文件名/路径/大小/修改时间/扩展名，进度实时显示（扫描中 n/N），可重复扫描
- IDX-3 目录判重：路径归一化（含尾随反斜杠）后判重，重复添加拒绝
- IDX-4 重扫：每个已索引目录可手动重扫
- IDX-5 移除目录：可选连带删除其下文件记录（含标签），二次确认
- IDX-6 文件变更监听（v1.3 提速）：已索引目录增/删/改自动同步，实测约 **1 秒**（原要求 ≤10 秒）；监听到变化时前端轻提示
- IDX-7 缺失文件：磁盘上已不存在的文件标记缺失，一键清理（含级联删标签）
- IDX-8 文件类型识别：扫描时按扩展名自动归类：图片/PDF/Word/表格/PPT/文本/视频/音频/压缩包/其他
- **IDX-9 启动回扫（v1.3）**：每次启动自动重扫全部目录，补录程序关闭期间错过的变更（后台异步，不阻塞启动）
- **IDX-10 移动/改名标签接力（v1.3）**：扫描按「文件大小 + 修改时间」识别缺失行，移动/改名后 **file_id 不变、标签全保留**；覆盖同目录改名、跨已索引目录移动、移出再移回、移动期间程序关闭（下次启动回扫接力）等场景

### 2.2 标签体系（核心）
标签模型：标签为"类型 + 值"二维结构挂在文件上：(file_id, type_id, value)；同一类型可挂多个值（叠加不覆盖）；重复打标幂等；标签名/值统一进全文索引，打标即搜。

标签类型管理（类型、名称、数量完全自定义）：
- TT-1 新建类型：设置区顶部：名称 + 枚举/自由输入 + 新建按钮
- TT-2 改名：单击选中、双击行内编辑；改名后已挂标签与搜索索引同步
- TT-3 输入模式：枚举（受控下拉）↔ 自由输入（自动补全）随时切换
- TT-4 排序：每类型行 ▲▼ 上移/下移，筛选面板与打标下拉同步生效，重启不丢
- TT-5 筛选面板显示/隐藏：每类型可设为"不在筛选面板显示"（黄色标识），打标与搜索不受影响
- TT-6 删除类型：级联删字典值与已挂标签，显示受影响文件数后二次确认
- TT-7 预设类型：开箱自带 9 类（可增删改）：物料类型、用途标签、适用渠道、保密级别（公开/内部/机密）、版本状态、所属产品/项目、名称标签、重要程度、内容说明
- **TT-8 自由值字典自动登记（v1.3）**：自由类型打过的值自动登记进字典（含启动回填历史值），保证所有使用中的值都可在设置中改名/移动/删除

字典值管理（枚举下拉项）：
- TV-1 新增值：输入框回车/按钮添加；取值动态增长不设上限
- TV-2 改名：值 chip 双击或 ✎ 按钮；改名同步更新所有已挂标签与索引
- TV-3 删除值：级联移除该值的所有标签，确认时显示影响文件数
- TV-4 移动值：⇄ 按钮移动到任何已有类型，或输入新类型名自动创建并归入；带走全部已挂标签，FTS 同步
- TV-5 未分类机制：快速添加匹配不到类型时自动归入"未分类"（不存在自动创建）；其中值可通过 TV-4 随时归组；"未分类"类型受保护不可删改，类型可整类去标

"内容说明"标签：专为"这个图片/文件是什么"设计；自由文本、默认不出现在筛选面板、在详情区置顶显示；打标后可被搜索直接命中。

### 2.3 打标
- TAG-1 单文件打标：**单击文件右侧详情面板自动打开**（v1.3 修复）；按类型添加；枚举=多选复选面板（带过滤、已挂标记），自由输入=逗号/顿号/分号分隔一次加多个
- TAG-2 批量打标（v1.3 增强）：勾选/Shift/Ctrl 多选或全选后批量打标/去标：
  - **零选择直输**（v1.3）：顶部批量工具条不选类型，直接输入值回车即打标，自动归"未分类"；支持逗号分隔多值
  - 按类型打标：选定类型后打标（枚举类型变为下拉选值）
  - **批量去标**（v1.3）：填值=移除指定值；**不填值=移除所选文件该类型下全部标签**（整类去标，带确认）
  - **一键清空全部标签**（v1.3）：移除所选文件所有类型的全部标签（红色按钮，带确认）
- TAG-3 快速添加：详情区统一输入框，边输入边实时提示：跨全部类型前缀匹配（显示 值+类型名+次数，精确匹配置顶徽标），点击提示项直接挂上；一个值多类型时列出候选点选；无匹配回车自动归"未分类"；支持逗号分隔多值
- **TAG-4 多选批量模式（v1.3）**：多选时右侧面板自动切换批量模式——快速添加、按类型勾选、标签去除全部作用于所有所选文件；标签区显示所选文件标签**并集**，"部分文件拥有"的标签带「部分」徽标；枚举复选框区分 已挂(全部)/部分/未挂 三态；锚点为最后点击的文件（上限 50 个文件的并集展示，操作不受限）
- TAG-5 打标即生效：标签立即进全文索引，立即可搜

### 2.4 检索
- SR-1 输入即搜：文件名/路径/标签值统一匹配，不按回车；中文子串匹配（FTS5 trigram，短词自动 LIKE 降级）
- SR-2 组合筛选：左侧面板按类型分组勾选；同类型多选=或，跨类型=且，与关键词 AND
- SR-3 文件类型筛选：面板顶部"文件类型"分组（每类显示数量），可与其他筛选组合；分组可折叠
- SR-4 一键清除：顶部"全部清除"常驻（无筛选时置灰）；每个分组有自己的"清空"按钮
- SR-5 已选条件汇总：顶部 chips 展示全部已选条件，单个可移除
- SR-6 排序分页：名称/修改时间/大小 × 升降序（偏好记忆）；快捷"只看定稿"（**v1.3 放宽：任意类型的标签值含"定稿"即命中**，不限类型名）
- SR-7 搜索健壮性：特殊字符不崩、注入白名单拦截、乱词返回空
- SR-8 字段化检索（科学检索法）：搜索框支持 `标签类型:值` 语法：空格=且（如 `保密级别:机密 用途:归档`）、`|`=或（如 `保密级别:机密|内部`）、全角冒号等价、值精确+包含匹配、左侧非类型名自动退化为普通关键词、与面板筛选叠加 AND；解析出的条件在已选区只读展示
- **SR-9 未打标签筛选（v1.3）**：顶栏 🔔「未打标签 N」徽标实时显示无任何标签的文件数；点击即筛选全部未打标签文件（chips 展示、可取消）

### 2.5 文件操作与视图
- OP-1 打开文件：双击用系统默认程序打开
- OP-2 右键菜单：打开 / 打开所在文件夹 / 复制路径 / 编辑标签
- OP-3 双视图：表格（虚拟化）与缩略图网格（懒加载、滚动到可视区才生成、按内容版本缓存）切换
- OP-4 详情预览：右侧面板显示预览图与全部标签、类别、大小、时间；多选时切换为批量模式（见 TAG-4）
- OP-5 缺失标识：缺失文件在列表标记
- OP-6 缩略图防串图：缩略图 URL 含内容版本号（mtime），文件变化或换库后缓存自动失效

### 2.6 数据管理
- DA-1 导出备份：JSON（完整，按类型名对齐可跨库还原）/ CSV（带 BOM 可直接 Excel）
- DA-2 导入还原：JSON 导入，跨库还原按类型名对齐（历史删过类型也不挂错）
- DA-3 便携：数据文件位置/端口存 config.json，可改；整个目录可拷走
- **DA-4 端口自动回退（v1.3）**：启动时 48765 被占用则自动改用下一个空闲端口并提示（重复双击不会开出多个实例，检测到已运行直接打开浏览器）；可用 `TV_PORT` 环境变量或 config.json 固定端口
- **DA-5 静默启动（v1.3）**：便携版提供无黑窗口的后台启动方式（vbs），日志写入 `app\logs\tagvault.log`（2MB 轮转）；致命错误弹窗提示

## 3. 界面布局
顶栏：标题 + 搜索框（输入即搜）+ 🔔未打标签徽标 + 排序/视图/设置 + n 条结果
左栏（筛选面板）：全部清除、文件类型▾（每类数量，可折叠）、各类型▾（分组清空按钮）
中栏顶部：**批量工具条**（选中 >0 时出现）：已选 N + 类型下拉（默认"不指定类型（未分类）"）+ 值输入（回车即打标）+ 批量打标 / 批量去标 / 清空全部标签 / 全清选择
中栏：结果列表（表格虚拟化 / 缩略图网格懒加载），多选/Shift 范围选/右键菜单/双击打开
右栏：详情与标签编辑——预览图、内容说明(置顶)、当前标签、[快速添加输入框]（实时匹配提示）、按类型添加标签；**多选时自动切换为批量模式（提示条 + 并集标签）**
设置弹窗：数据与端口 / 索引目录 / 标签类型管理（排序·显隐·字典值移动）/ 导入导出 / 缺失清理
三栏均可独立滚动。

## 4. 技术栈（供参考）
Node.js 20+（便携包内置 22）/ Express 4 / better-sqlite3（FTS5 trigram + 触发器同步）/ React 18 + Vite + TypeScript + Tailwind + zustand + @tanstack/react-virtual / chokidar（实时监听）/ sharp（缩略图）/ SSE（进度与变更推送）/ Vitest + Supertest（49 个自动化测试）。Windows 平台；文件夹选择框由常驻 PowerShell 宿主进程提供（READY 握手协议：预热 WinForms 对话框 15s 超时降级 COM），COM 方式兜底。

## 6. 验收要点
启动：`npm start` 一条命令启动并自动打开浏览器 localhost:48765（端口占用自动回退）；
打标：快速添加框输入 1 个字即出匹配提示；无匹配回车进"未分类"；"未分类"的值可在设置里 ⇄ 移动到其他类型；
批量：多选后顶部工具条**不选类型直接回车即可批量打标（归未分类）**；批量去标不填值=整类去除；一键清空全部标签；多选时右侧面板自动进批量模式，操作作用于全部所选；
自动更新：运行中新增文件约 1 秒自动入库并弹提示；启动回扫补录；🔔 未打标签计数准确；
移动追踪：文件改名/移动（含跨目录）标签保留；移出标记缺失、移回恢复；
检索：输入即搜；组合筛选或/且语义正确；全部清除与分组清空可用；`类型:值` 字段化检索；只看定稿（任意类型）；
缩略图：与文件一一对应，文件修改后自动更新；
滚动：三栏独立滚动；
数据：导出 JSON → 清库 → 导入还原，标签按类型名对齐无错挂；
回归：需有自动化测试脚本且全绿（当前 49/49）。

## 非功能
搜索性能：万级记录 ≤200ms（实测中位 8ms）；扫描性能：万级文件入库需可接受（进度显示）；单文件 SQLite 存储；完全离线零网络请求。
